# Menu-Button 🍔

제타(zeta-ai.io) 웹페이지에서 사용하는 플로팅 북마클릿입니다.

## 기능
- 현재 플롯의 편집 페이지 열기 (채팅방에서 플롯 확인 지원)
- 공개 플롯을 비공개 사본으로 생성 (1~20개)
- 드래그 가능한 원형 🍔 버튼, 접기/펼치기
- 이동 및 크기 조절이 가능한 화이트 미니멀 패널

## 설치
1. [bookmarklet.js](./bookmarklet.js) 파일의 **전체 내용**을 복사합니다.
2. 브라우저에서 북마크를 만들고 주소(URL) 칸에 붙여넣습니다.
3. zeta-ai.io의 플롯 또는 채팅방에서 해당 북마크를 실행합니다.

## 인증
이 북마클릿은 실행 후 웹제타가 보내는 정상 API 요청에서 인증 정보를 일시적으로 참조합니다. 로그인 토큰을 별도로 입력하거나 파일에 저장하지 않습니다.

- 비캐 가두기: 웹제타의 **스크랩** 버튼을 눌러 인증 요청을 발생시키세요.
- 채팅방 플롯 편집: **메뉴 버튼**을 누르거나 **말풍선을 길게 눌러** 인증 요청을 발생시키세요.

## 주의
- 웹제타의 내부 API 또는 화면 구조가 변경되면 작동하지 않을 수 있습니다.
- 비공개 사본 생성은 실제 계정에 변경을 일으킵니다. 처음에는 1개로 테스트하세요.
- 타인이 만든 플롯은 편집 권한이 없을 수 있습니다.

버전: v9

- 동일한 크기의 둥근 플롯 편집 / 비공개 전환 버튼과 회색 구분선
- 오른쪽 원형에 가까운 개수 입력창
- 상단 원형 `!`(사용 안내), `−`(최소화), `×`(종료) 버튼
- 사용 안내는 `!` 버튼으로만 열리며, 항목별로 정리되어 표시됩니다.
- 최초 실행 시 작은 🍔 버튼으로 시작하고 위치와 크기를 기억합니다.
- 편집 권한 확인은 아직 웹제타의 실제 응답 형식 검증이 필요합니다.
